# Vuxo 0.0.3

Grafica e audio del mondo. / World graphics and audio.

## Player-visible changes / Per i giocatori

- **IT:** Il bosco ha alberi, cespugli, recinzioni e accampamenti disegnati (asset CC0 di Kenney), un ciclo di luce lunare/alba/crepuscolo di 8 minuti, lucciole, scintille attorno ai portali e creature decorative (falene e coniglietti) che non influenzano il gioco. Nuovi suoni (passi, clic, apertura portali, ambiente notturno sintetizzato) con interruttore nella barra superiore, attivi solo dopo il primo gesto dell'utente. Nuova pagina **Crediti e licenze** (`/credits`, raggiungibile dalla pagina Versione). / **EN:** The woodland now has hand-placed trees, bushes, fences and camps (Kenney CC0 assets), an 8-minute moonlight/dawn/twilight cycle, fireflies, portal sparks and decorative creatures (moths and rabbits) that never affect gameplay. New sounds (footsteps, clicks, portal entry, synthesised night ambience) with a toggle in the top bar, played only after the first user gesture. New **Credits and licenses** page (`/credits`, linked from the Version page). Con *reduced motion* la luce resta ferma, senza lucciole n├⌐ movimento delle creature. / With *reduced motion* the light stays fixed, with no fireflies or creature movement.

## Known limitations / Limiti noti

- Nessuna modifica alle regole di gioco o allo schema/database. Le note infrastrutturali in questa release descrivono il mapping host API e le modalità tunnel; non è stato eseguito alcun deploy reale.
- Collaudo visivo su dispositivi reali ancora aperto (#165). Il test `multiplayer.spec.ts` sul blur della tastiera e' instabile con molti worker paralleli (riprodotto anche su 0.0.2).

## Infrastructure / Infrastruttura

- **IT:** Il Compose production predefinisce il mapping API su `127.0.0.1:64000` (porta container invariata `8080`); database, Redis e Ollama restano senza porte host. Sviluppo e deploy Linux esistente mantengono le proprie porte (`8080` per dev/deploy esistente, porta isolata nei test Docker). Documentate le due modalità alternative del tunnel: `cloudflared.exe` sull'host verso `127.0.0.1:64000`, oppure connector Docker verso `api:8080`. Il contesto Docker esclude `.local/`. L'environment di esempio usa tenant Microsoft `consumers`, mentre la guida agenti chiarisce ruoli e flag workflow. L'endpoint pubblico è stato verificato HTTP 200, ma al momento raggiunge lo stack locale di test (`0.0.3+local.local`, commit `unknown`), non una release immutabile GHCR.
- **EN:** Production Compose defaults the API host mapping to `127.0.0.1:64000` (container port remains `8080`); database, Redis and Ollama have no host ports. Development and the existing Linux deployment retain their separate ports (`8080` for dev/existing deploy, an isolated port for Docker tests). Documented the two alternative tunnel modes: host `cloudflared.exe` to `127.0.0.1:64000`, or the Docker connector to `api:8080`. Docker build context excludes `.local/`. The example environment uses the `consumers` Microsoft tenant, and the agent guide clarifies workflow flags and runtime variables. The public endpoint was verified HTTP 200, but currently reaches the local test stack (`0.0.3+local.local`, commit `unknown`), not an immutable GHCR release.
